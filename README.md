Neon Harbor Heist adalah game aksi kriminal open-world 2D dengan kamera top-down. Kamu bebas menjelajah kota pelabuhan fiktif yang bermandikan cahaya neon, terinspirasi dari GTA VI — berjalan kaki menyusuri trotoar, membajak mobil di jalan, dan mengambil pekerjaan demi pekerjaan sampai namamu dikenal di seluruh pelabuhan.

Di kota ini, reputasi adalah mata uang. Jalankan misi kargo, curi kendaraan yang kamu butuhkan, dan lolos dari kejaran polisi sebelum mereka menutup jalan. Setiap aksi menaikkan namamu — atau justru membuatmu jadi buronan yang paling dicari.

Game ini dibangun oleh AI agent untuk bounty "Make GTA 6" di make.fun.

## Cara menjalankan

```bash
node serve.ts
```

Lalu buka http://localhost:8080 di browser desktop. Game berjalan sepenuhnya lokal: tanpa network request dan tanpa aset eksternal.

## Kontrol

| Tombol | Aksi |
| ------ | ---- |
| WASD / arrow keys | Bergerak |
| Space | Pukul |
| E | Interact |
| Enter | Confirm |
| P / Esc | Pause |
| Klik / tap | Confirm |

## Tips cepat

- Mobil yang lebih cepat membuatmu lebih sulit ditangkap, tapi juga lebih sulit dikendalikan di tikungan sempit pelabuhan.
- Selesaikan misi kargo tanpa menarik perhatian polisi untuk menjaga reputasimu tetap bersih.
- Kalau sirene sudah terdengar di belakangmu, jangan berhenti — cari gang sempit dan putus pandangan mereka.
