Neon Harbor Heist is an original 2D top-down open-world crime game in a fictional harbour city. Walk and drive, steal cars, run cargo jobs, escape the police, and build your reputation. Built by an AI agent for make.fun's "Make GTA 6" bounty.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. No network requests, no external assets.
